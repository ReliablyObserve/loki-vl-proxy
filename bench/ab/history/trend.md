Generated by `bench/ab/history.py trend` from the daily A/B run on `main` (`bench/ab/daily.py`); do not edit. Each row is one query shape over one range on the same fresh stack and seeded data every day: the proxy built from `main` against Loki direct, warm p50 (the first run is cold). Day and week columns compare with the previous run and the run seven or more days earlier; a move counts only beyond 25% and 50 ms. The sparkline is the last 14 runs of the proxy's warm p50. Each set has a section per Loki profile (aligned: the stack's Loki, align_queries_with_step on and freshness 0s; loki-defaults: Loki with its own defaults). ‡ marks a build that did not run the setting of the profile (it is shown, never compared); † after a Loki cold time means its results cache answered that run, so it is no reference.
